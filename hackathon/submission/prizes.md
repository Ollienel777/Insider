# Prize evidence

One row per requirement in [`SPEC.md` §3](../SPEC.md#3-prize-requirements),
checked against the code on `main`. The requirement column quotes SPEC §3,
which quotes [`tracks/prizes.md`](../tracks/prizes.md).

**Read this first.** No API keys exist in this project's runs. Everything below
runs in fake mode: fixture buildings, a hand-authored floor and recorded model
turns. The live CoStar, Vexcel, Matterport, Anthropic and Bedrock paths are
written and unit-tested against stubs, but **none has been run against the
real service**. The top bar's `FIXTURES` chip says so on every screen.

**Statuses.** **Met**: true today, nothing live involved. **Met on fixtures
(live untested)**: true in fake mode; the live path is written but has never
run. **Partly met**: some of it is true today; the row says what is missing.
**Not met**: not true today; the row says what it needs.

The open questions Q1 to Q7 are in [`SPEC.md` §11](../SPEC.md#11-open-questions)
and on the status issue,
[#1](https://github.com/Ollienel777/heist-anywhere/issues/1).
